# Koravik Project Zero

**Status:** Complete  
**Completed:** July 28, 2026  
**Next milestone:** Blueprint v1.0 review  
**Next implementation phase:** Build 001 — Foundation

Project Zero closes the discovery and product-definition phase of Koravik Final. It establishes the product identity, experience principles, design direction, governance expectations, and implementation gate that must guide future engineering.

## Governing statement

> The blueprint is a product. The software is its implementation.

When implementation and the approved blueprint disagree, implementation must stop. The disagreement must be resolved through an explicit documentation revision or accepted architecture decision record before work continues.

## Project Zero outcome

Koravik is defined as an operating system for intentional living: a modular platform that reduces friction between intention and action while preserving meaning, agency, privacy, accessibility, and the option for real-life facts to influence persistent narrative Worlds.

Project Zero authorizes completion of Blueprint v1.0. It does not yet authorize production implementation.
