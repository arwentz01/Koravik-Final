# Companion Help and Proposal Center

**Status:** Implemented vertical slice

## Player outcome

The Companion home is now a complete help and proposal center. A person can ask for one bounded next step, see which proposals need a decision, distinguish approval from execution, and review the complete proposal history without mistaking suggestions for saved records.

## Visible workflow

- the request form states that only entered text is used;
- a three-state summary distinguishes decisions needed, approved proposals, and executed source records;
- the control model explains draft, version-specific review, and owner-revalidated execution;
- proposal cards show status, destination, version, and proposal type;
- Quest and Chronicle proposal paths retain edit, approve, dismiss, and explicit execute actions.

## Boundaries

Companion owns proposals, reasoning, and source context. Quests and Chronicle own executed records. Approval alone creates no District record, dismissal has no penalty, and Companion does not silently search private records.
