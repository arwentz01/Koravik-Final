# Organization Operating Dashboard

**Status:** Implemented vertical slice

The Organization home now acts as a role-aware operating dashboard. It summarizes active membership, Gather-owned events, Beacon-owned links, and pending invitations; explains the current member's contextual capabilities; and keeps creation, governance, proposals, activity, settings, teams, domains, and recovery in one coherent workspace.

Organization roles never grant Platform authority. Gather retains event truth, Beacon retains public-link truth, and accepted Quest proposals become personal Quests only after recipient consent.
