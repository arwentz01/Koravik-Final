# Gather Participant Journey

**Status:** Implemented vertical slice

The secure RSVP management link now provides one participant-facing journey across RSVP, signup commitments and waitlists, host-recorded attendance, and optional follow-up. Participants can update or cancel an RSVP, choose an available signup, see active or waitlisted commitments, release a commitment, review check-in state, and deliberately start a private Chronicle reflection after a completed event.

Cancelling releases active commitments and allows existing Gather waitlist promotion rules to run. Attendance remains Gather-owned host evidence; Chronicle memory is never created automatically.
