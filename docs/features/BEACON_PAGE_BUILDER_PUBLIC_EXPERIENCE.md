# Beacon Page Builder and Public Experience

**Status:** Implemented vertical slice

Beacon pages now begin as private drafts and open in an accessible builder with a mobile preview, explicit private/unlisted/public visibility, a publication warning, and durable revision history. Saved unlisted or public pages render in a focused mobile-first public shell with a visible Beacon and visibility label.

Beacon owns presentation and revision history. Source modules retain any referenced event, organization, or contact truth. Private pages cannot be resolved publicly.
