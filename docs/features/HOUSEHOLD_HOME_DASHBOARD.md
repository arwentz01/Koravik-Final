# Household Home Dashboard

**Status:** Implemented vertical slice

The Household home is now a private, role-aware coordination dashboard. It summarizes members, private Gather events, private resources, and proposals waiting for the current person. It exposes contextual capabilities, recent Household activity, consent-first responsibility proposals, invitations, settings, lifecycle recovery, and ownership controls without resembling a public or corporate workspace.

Households remain optional and private by default. Gather owns event truth; accepted responsibilities become personal Quests only after recipient consent.
