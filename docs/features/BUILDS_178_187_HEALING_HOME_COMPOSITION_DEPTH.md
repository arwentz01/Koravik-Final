# Builds 178–187: Healing Home Composition Depth

Builds 178–187 deepen Healing Home as a source-aware place layer. The house now feels more connected while continuing to respect ownership boundaries.

## Implemented slices

1. Health Garden — `/home/rooms/health_garden` provides a safe Health doorway without reading notes, diagnosing, or scoring.
2. Gather Table — `/home/rooms/gather_table` orients event continuity while keeping RSVP, signup, attendance, communications, and follow-up in Gather.
3. Healing Home Composition Command Center — the Home command center now exposes source-aware rooms, room-note search, and Companion room-note consent.
4. Healing Home Source Matrix — `/home/sources` now includes Health, Gather, Companion room-note consent, and explicit exclusions.
5. Room Note Search — global search can find private Healing Home room notes and labels them as Healing Home-owned results.
6. Room Note Search Boundary Copy — search results explain that room notes stay in Healing Home unless explicitly copied elsewhere.
7. Companion Room-Note Consent — Companion context permissions now include `healing_home.room_notes`.
8. Companion Context Mapping — selected Healing Home context maps to the room-note permission instead of falling through to pillar summaries.
9. System Health Checkpoint — the unauthenticated health checkpoint now identifies Build 187 and `healing-home-composition-depth`.
10. Release Contract Coverage — the release suite now checks the new source-aware Healing Home, Search, Companion, and checkpoint seams.

## Contract

- Healing Home may compose Health and Gather doorways but does not own Health observations, Gather event truth, public previews, or communications.
- Room notes remain Healing Home-owned records and are searchable only as account-owned private results.
- Companion may use Healing Home room-note context only after the dedicated permission is enabled.
- Build 187 is the current operational checkpoint.
