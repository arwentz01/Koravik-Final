# Build 005 — Epic Ordinary Continuation

## Player-visible outcome

A Player can enter Epic Ordinary as a persistent World, meet the Caretaker through durable dialogue, make a meaningful choice about how support should feel, and later see that choice and real-life Quest completions alter the World relationship and continuation.

## Scope

- Epic Ordinary World home and chapter continuation
- persistent Caretaker NPC and Player relationship
- authored dialogue scenes and meaningful choices
- durable narrative flags and choice history
- Quest-completion-driven relationship changes through Platform events
- explainable provenance for relationship changes
- idempotent event consumption
- server-rendered accessible UI and MySQL validation

## Deferred

- Creator Studio authoring UI
- multiple installed Worlds
- inventory and rewards
- broad branching
- Companion-generated dialogue
